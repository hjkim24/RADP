\subsection{Failure recovery survives where baselines abort}\label{sec:eval:recovery}
% Outline (~0.5 page, two paragraphs covering the two topologies):
% (a) Star topology (EXP-D2.1, A2 N=5): 0/300 token loss across 5
%     trials. Recovery step mean 617 ms, p95 670 ms, 100 ms tight
%     spread. R={} baselines abort after the 17-20 in-flight tokens
%     accumulated before the SIGKILL.
% (b) Chain topology (EXP-D3 Phase 3 + 3.2):
%   - Sync chain, 4-stage, on-6 SIGKILL mid-stream: 60/60 coherent
%     tokens. Coord journal shows the trailer attribution path
%     fires: "chain failure for already-dead on-6[10..14];
%     finalising recovery (rewire + replay)". The trailer is
%     ESSENTIAL: heartbeat had already substituted ao-1 as the
%     backup, but the trailer's (10,14) range maps via the
%     original placement to on-6 (the truly dead worker).
%   - Async chain, same setup (post the trivial TimeoutError
%     fix, commit bf238b2): also 60/60. Attribution falls back
%     to head_stage when heartbeat loses the race; R+psi
%     feasibility preserves correctness at the cost of an extra
%     hop.

%     exactly 16 mirror pushes (8 steps * 2 non-first stages).

\subsection{Latency placement strictly dominates throughput placement across 28 measurement points}\label{sec:eval:matrix}
% Outline (~0.8 page — the headline result):
% - Big 2x2x{C,depth} matrix. The figure version is a compact
%   heatmap-coloured table; the prose calls out three deltas:
%   (i) L > T at every one of the 28 points across two chain
%       lengths * four cells * 3-4 C levels;
%   (ii) async > sync everywhere at C >= 4, biggest at
%       C=16 throughput placement (+47%);
%   (iii) async gain is chain-length-INDEPENDENT (3-stage T@C=16
%       sync->async = +47%, 4-stage = +46%). The cost is O(C),
%       not O(stages * C).
% - Best operating point on this fleet: L+async @ C=16 = 41.7
%   tok/s (4-stage) vs worst (T+sync @ C=16) = 24.5 tok/s. +71%
%   span covered by two runtime knobs the operator can flip.
% - Caveat — stage count isn't a free knob: 3-stage L+async @ C=4
%   = 33.7 tok/s; 4-stage = 23.9 (-29%). Each Nano in the
%   4-stage chain gets only 1 layer to compute but pays a full
%   network hop. RADP's DP picks stage count cost-aware; we
%   forced 4-stage via fleet composition to expose this.
