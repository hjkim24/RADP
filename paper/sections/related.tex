\section{Related Work}\label{sec:related}

\subsection{Distributed LLM Inference and Fault Tolerance}

EdgeShard profiles per-layer execution time, memory, and inter-device
communication and assigns consecutive layers to heterogeneous edge and cloud
devices so as to minimize cumulative stage time or the slowest
stage~\cite{zhang2024edgeshard}; Jupiter partitions decoder layers under
memory and token-between-time constraints and adds pipeline-parallel prefill
and speculative decoding~\cite{ye2025jupiter}.  Both determine the active
placement only, so a failed device removes its layer range together with the
request state stored there.  Helix, HexGen, HexGen-2, Hetis, and LLM-PQ
solve placement, parallelism, or quantization as a coupled optimization over
datacenter GPUs of different classes~\cite{mei2025helix,jiang2024hexgen,
jiang2025hexgen2,mo2025hetis,zhao2024llmpq} without a mechanism for restoring
an interrupted request's KV state; HexGen reacts to a departed GPU by
re-running its placement search.  On edge pipelines, FTPipeHD replicates
training weights so training survives device failures~\cite{chen2024ftpipehd}
(a recovery unit of weights, whereas decoding must restore per-request KV
state within a token interval), and JARVIS evaluates route reconfiguration
and layer skipping, a degraded execution~\cite{sirera2024jarvis}.

\subsection{Recomputation}

Recomputation rebuilds lost KV state by executing model layers again.  Petals
keeps on the client the inputs sent to each remote block range and, when a
server disconnects, replays them through a replacement that already holds
the missing blocks~\cite{borzunov2023distributed}.  This spares the other
stages, but the failed layers still execute once per prior position, and a
peer must already store the same block range, duplicate capacity that the
no-spare-device setting studied here lacks.  Our Recompute baseline
(Section~\ref{sec:eval:setup}) is the corresponding lower bound on retained
state: it replays every stage from position zero.

\subsection{Replication}

DejaVu streams each pipeline worker's KV cache to a replica and, after a
failure, restores the latest acknowledged replica and recomputes only the
unreplicated tail~\cite{strati2024dejavu}; protecting all stages stores the
sum of their KV caches.  KevlarFlow copies PagedAttention KV blocks to the
corresponding stage of another model instance~\cite{qian2026kevlarflow}, and
LUMEN checkpoints requests in host memory on holders that each hold a
complete model~\cite{cao2026lumen}; neither places layer partitions and
backup weights jointly across devices that cannot each hold the full model.

\subsection{Reconfiguration}

SpotServe replans parallelism when a cloud provider announces preemption and
migrates parameters and KV context before the instance is
lost~\cite{miao2024spotserve}, a path that depends on advance notice and a
grace period.  Parallax serves LLMs over a decentralized pool of
heterogeneous GPUs and, on a departure, de-allocates the departed layers and
may re-run allocation~\cite{tong2025parallax}, without restoring the KV state
of the interrupted request.  Neither characterizes the unassisted path with
no advance notice and no surviving checkpoint, which our Reconfigure baseline
(Section~\ref{sec:eval:setup}) measures.

\subsection{Parity}

Erasure coding has protected computation and cached state before: coded
computation recovers straggling or failed workers' matrix products from
parity workers~\cite{lee2018speeding}, Parity Models learn a parity model so
that a prediction-serving replica can be reconstructed from coded
queries~\cite{kosaian2019parity}, EC-Cache stores cached objects as
erasure-coded splits~\cite{rashmi2016eccache}, and regenerating codes bound
the bytes a repair must read~\cite{dimakis2010network}.  \sys{} applies
the same idea to the KV state of a pipeline, where the coded unit is a
stage's per-token column and the repair reads the surviving stages'
columns.  GhostServe replaces full KV replicas with erasure-coded checkpoints inside a
tensor-parallel server, generating XOR, RDP, or Reed--Solomon parity with
fused GPU kernels into host memory~\cite{jayakody2026ghostserve}; its
protection domain is the GPU shards of one node with a large host-memory
tier.  \sys{} encodes KV columns across the protected non-head stages of a
pipeline, so one parity column occupies the size of the largest protected
column rather than the sum, a second column over GF($2^8$) covers two
simultaneous failures, and the placement $\psi$ and backup mapping $R$ are
selected together.
