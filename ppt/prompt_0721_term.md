# 0721 덱 — `장애 깊이` 표현 교체 (이것만 한다)

덱의 다른 것은 **하나도 건드리지 마라.** 슬라이드를 추가·삭제·재배치하지 마라.
좌표·폰트·색·표·쪽번호 전부 그대로 둔다. 할 일은 **문구 5곳 교체**와
**그림 1장 재삽입**뿐이다.

## 왜

P는 **죽기까지 만든 토큰 수**(생성 진행도)다. 그런데 `깊이` 라고 부르면 파이프라인
몇 번째 stage 인지로 읽힌다. 하필 victim 의 체인 위치도 따로 바꿔가며 측정하므로
(첫 워커 `on-1` vs 중간 `on-6`) 서로 다른 두 가지가 한 단어를 나눠 쓰고 있다.

## 작업 1 — 문구 5곳 교체

아래 문자열을 찾아 그대로 바꾼다. 해당 슬라이드의 다른 요소는 손대지 마라.

| 슬라이드 | 찾을 것 | 바꿀 것 |
|---|---|---|
| 4 | `• 둘 다 모델을 다시 돌림 → 비용이 장애 깊이 P에 비례` | `• 둘 다 모델을 다시 돌림 → 늦게 죽을수록 비쌈 (P에 비례)` |
| 7 (표) | 행 이름 `깊이 P당 비용` | `P 1개당 추가 비용` |
| 9 (소제목) | `a. 복구 시간이 장애 깊이와 독립적` | `a. 복구 시간이 장애 시점과 독립적` |
| 9 | `• 기울기 = 깊이 P 당 추가 비용` | `• P = 죽기까지 만든 토큰 수. 기울기 = P 1개당 추가 비용` |
| 10 | `• parity 기울기는 장애 깊이·victim 위치 모두와 무관` | `• parity 기울기는 장애 시점·victim 위치 모두와 무관` |

9번 소제목은 **굵게**를 유지한다. 10번 결론 줄은 **굵게**를 유지한다.

## 작업 2 — 9번 TTR 그래프 그림 재삽입

축 라벨이 `failure depth P` 에서
`failure position P (tokens generated before the crash)` 로 바뀌었다.
슬라이드에 박힌 그림은 옛 축이라 문구만 고치면 그림과 어긋난다.

- 파일: `paper/figures/fig_recovery_ttr_slide.png`
- **6.42 in, 배율 100%**, 지금 그림이 있는 자리 그대로 (L 5.30 T 1.75)
- 기존 그림은 지우고 새로 얹는다. 크기를 조절하지 마라

## 끝나고 확인할 것

- 덱 어디에도 `깊이` 라는 말이 남아 있지 않은지
- 슬라이드 수가 그대로 **11장**인지 (하나도 늘거나 줄지 않아야 한다)
- 9번 그림의 가로축이 `failure position P (tokens generated before the crash)` 인지
- 9번 그림 배율이 100% 인지
