# Progress Report — 디자인 시스템

주간 진행보고 덱의 규격. **매주 이 문서 + `template/radp-progress-template.pptx` 를 기준으로 만든다.**

목적은 "예쁘게"가 아니라 **매주 같은 결과가 나오게** 하는 것. 그래서 규칙을 형용사가 아니라 숫자로 적는다.
("간결하게", "깔끔하게" 같은 지시는 매번 다른 결과가 나온다.)

## 2. 슬라이드 해부 (좌표 고정)

단위 inch, 캔버스 13.33 × 7.50 (16:9).

```
섹션 밴드      L 0.00  T 0.00  W 13.33  H 0.52    28pt
워크스트림     L 0.05  T 0.60  W  6.00  H 0.50    24pt  #0070C0
소제목         L 0.05  T 1.10  W  8.00  H 0.37    16pt
콘텐츠 영역    y 1.75 ~ 6.35            (좌여백 0.63 / 우여백 0.63)
캡션           콘텐츠 하단 바로 아래                12pt
쪽번호         L11.17  T 7.22  W  0.70  H 0.26    12pt
```

**표지(1번)는 건드리지 않는다.** 로고·문구·좌표 고정. 폰트만 Century Gothic 으로 통일되어 있다.

## 4. 색

**본문 텍스트는 전부 `404040` 한 색.** 강조는 색이 아니라 **굵게**로 한다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 본문 | `404040` (dk1) | 모든 텍스트 |
| 제목 강조 | `0070C0` (accent3) | 워크스트림 제목 전용 |
| 경고 · 문제 | `CB3E3A` (accent6) | 버그/한계 표시. 슬라이드당 1회 |
| 배경 톤 | `E5E8E8` (lt2) | 표 헤더 배경 |

`FF0000` 등 팔레트 밖 색 금지. (원본 템플릿이 순수 빨강을 쓰고 있었으나 `CB3E3A` 로 교체)

### 반복 대상 색 고정 (주 단위 비교 가능성)
같은 대상은 **매주 같은 색**으로 그린다. 청중이 색으로 대상을 기억하게 하기 위함.

| 대상 | 색 |
|---|---|
| full-replay | `CB3E3A` |
| surgical | `F08F1E` |
| parity | `77B142` |
| baseline / 복구 없음 | `808080` |

## 5. 이 랩은 시각물 우선이다

원본 템플릿 24장에 **그림 23 + 표 5**. 콘텐츠 슬라이드당 시각물 1개꼴이고, 텍스트는 그림 주변의 짧은 라벨이지 불릿 목록이 아니다.

**규칙: 콘텐츠 슬라이드는 시각물 1개를 기본으로 잡는다.** 시각물 없이 불릿만 있는 슬라이드는 이 덱에서 비어 보인다(2026-07-21 덱에서 실제로 겪음).

시각물이 정말 없으면 표로 대체하고, 표도 없으면 그 내용은 다른 슬라이드에 합친다.

## 6. 표 규격

- **최대 4행 × 3열.** 넘으면 잘라서 두 장으로. (원본의 9×3 은 읽히지 않는다)
- 헤더: **굵게**, 배경 `E5E8E8`. 본문 16pt, 행이 5개 이상이면 14pt
- 숫자는 **오른쪽 정렬**, 단위는 셀이 아니라 **헤더**에 (`TTR (초)`)
- 세로 괘선 없음. 헤더 아래 가로선 1개만
- 강조는 **굵게**로. 셀 배경색으로 강조하지 않는다
- 표 아래 **결론 한 줄**을 반드시 붙인다 (`• 표에서 읽어야 할 것`)

## 7. 그림 · 차트 규격

### 7.1 슬라이드용 그림은 논문용과 다르게 만든다
`paper/figures/_common.py` 는 논문 2단 조판 기준 **8pt** 폰트다. 이걸 그대로 슬라이드에 넣으면 글자가 안 보인다.

**규칙: 슬라이드에 놓일 크기 그대로 만들고, 폰트를 덱 스케일로 올린다.**

```
figsize      = 슬라이드에서 차지할 크기 그대로 (예: 7.4 × 4.6 in)
축 라벨       14pt
눈금          12pt
범례          12pt
주석/수치      13pt
선 두께        2.0
dpi          300 (png) / pdf 동시 출력
```
1:1 크기로 만들면 PowerPoint 에서 확대·축소가 없으므로 글자 크기가 덱과 일치한다.

### 7.2 그림 안에 넣지 않을 것
- **제목** — 슬라이드 제목이 그 역할을 한다. 중복이면 슬라이드 제목을 지우는 게 아니라 그림 제목을 지운다
- 범례 박스를 축 밖에 두어 여백을 먹는 것 — 축 안에 넣는다
- 격자선 과다 — `alpha 0.3` 이하 옅게

### 7.3 색
§4의 **반복 대상 색 고정**을 따른다. matplotlib 기본색(`#1f77b4` 등) 대신 덱 팔레트를 쓴다. 그래야 슬라이드와 그림이 같은 덱으로 보인다.

### 7.4 캡션
그림 바로 아래 12pt 한 줄로 **환경 / 조건 / 유효 샘플 수**. 예:
`OPT-350M 24층 / 5-stage 이종 체인 / 15개 트라이얼 전부 유효`

## 8. 슬라이드 패턴 카탈로그

템플릿의 예시 슬라이드 번호와 대응한다. 새 레이아웃을 발명하지 말고 여기서 고른다.

| 패턴 | 템플릿 | 용도 | 구성 |
|---|---|---|---|
| **P1 피드백↔대응** | 3번 | §1 요약 | 2열 표. 좌=지적, 우=대응 |
| **P2 그림 우선** | 4번 | §2 주력 | 좌 라벨 3줄 + 우 대형 그림 + 캡션 |
| **P3 2단 비교** | 5번 | §2 | 좌/우 시각물 2개 + 하단 해석 1줄 |
| **P4 표 중심** | 6번 | §2 수치 | 3열 표 + 결론 1줄 |
| **P5 계획** | 7번 | §3 | 불릿 20pt |
| **P6 참고문헌** | 8번 | §4 | 12pt 목록 |

### 밀도 규칙
- 주 불릿 **3~5개**, 각 불릿 아래 **보조 1줄까지** (2단계까지만)
- 한 줄 **40자 이내**
- 문단·줄글 금지. 보조 줄도 한 줄로 끝낸다
- 상세 맥락은 슬라이드가 아니라 **발표자 노트**로. 단 **숫자와 근거는 슬라이드에 올린다**

### 슬라이드 제목은 라벨이 아니라 주장
- ✗ `실측 결과` → ✓ `parity는 깊이를 안 탄다`
- 청중이 그림을 볼 때 **무엇을 확인해야 하는지** 알고 보게 된다

## 11. 콘텐츠 정확성 규칙

발표 자료가 논문 근거로 이어지므로 아래는 서식보다 우선한다.

- **숫자를 지어내지 않는다.** 인테이크 폼에 없는 수치는 슬라이드에 넣지 말고 물어본다
- **다른 실행의 수치를 섞지 않는다.** 비교표에 올리는 값은 같은 실행에서 나온 것이어야 한다
- **한계를 빼지 않는다.** 선제적으로 밝히는 편이 질의응답에서 유리하다
- 선행연구 대비 주장은 **원문이 실제로 말한 범위**까지만

## 12. Claude for PowerPoint 에게 시키는 법

### 원칙: 템플릿이 서식을, 프롬프트가 판단을 담당한다
좌표·폰트·색·패턴은 **템플릿 파일 안에 이미 있고 어시스턴트가 직접 볼 수 있다.** 그러니 매주 그걸 다시 설명하지 않는다. 프롬프트에는 **파일을 봐도 알 수 없는 것**만 넣는다: 밀도 기준, 정확성 규칙, 제목을 주장으로 쓰라는 것, 이번 주 내용.

### 절차
1. `template/radp-progress-template.pptx` 복사 → `Progress Report_MMDD.pptx` 로 이름 변경
2. PowerPoint 에서 열기
3. §9 인테이크 폼을 채워서 아래 프롬프트와 함께 전달
4. §10 체크리스트로 검수. 어긋나면 그 항목만 지적해서 재요청

### 매주 쓰는 프롬프트 (이 블록을 복사해서 인테이크만 갈아끼운다)

```
이 덱은 주간 진행보고 템플릿이야. 3~8번이 패턴 예시 슬라이드니까
새로 만들지 말고 필요한 패턴을 복제해서 내용만 채워줘.

[서식]
- 템플릿의 기존 서식을 그대로 따를 것. 섹션 밴드/워크스트림 제목/쪽번호의
  위치와 크기를 바꾸지 말 것
- 본문 텍스트는 전부 404040 한 색. 강조는 색이 아니라 굵게
- 폰트 Century Gothic (수식 블록만 Consolas)
- em dash(—) 쓰지 말 것. 콜론이나 마침표로

[밀도]
- 주 불릿 3~5개, 각 불릿 아래 보조 1줄까지. 한 줄 40자 이내
- 문단·줄글 금지
- 콘텐츠 슬라이드마다 시각물(그림 또는 표) 1개 이상. 이 랩 관례임
- 표는 4행 3열 이내, 아래에 결론 한 줄
- 상세 맥락은 발표자 노트로. 단 숫자와 근거는 슬라이드에 올릴 것

[슬라이드 제목]
- 라벨이 아니라 주장으로. "실측 결과"(X) → "parity는 깊이를 안 탄다"(O)

[정확성]
- 아래 인테이크에 없는 숫자를 지어내지 말 것. 필요하면 물어봐
- 다른 실행에서 나온 수치를 한 표에 섞지 말 것
- 한계 항목을 빼지 말 것

[이번 주 내용]
<§9 인테이크 폼 채운 것을 여기 붙여넣기>

[마지막에]
슬라이드별로 (제목 / 불릿 수 / 시각물 유무 / 본문색 통일 여부)를 표로 보고하고,
밀도 기준을 넘긴 곳이 있으면 스스로 지적해줘.
```

### 자주 겪는 것
- **이미지 삽입 실패** — 로컬 파일을 못 집어올 때가 있다. 그러면 자리와 크기만 잡아두게 하고 직접 끌어다 놓는다. 프롬프트에 "안 되면 자리만 잡고 알려줘"를 넣어두면 조용히 넘어가지 않는다.
- **첫 결과가 성기다** — 이 랩 관례가 시각물 우선인데 텍스트만 만들면 비어 보인다. 시각물 1개 규칙을 다시 짚어주면 해결된다.
- **색이 다시 번진다** — 강조할 때 임의 색을 쓰는 경향이 있다. "강조는 굵게로만"을 매번 넣는다.
